# AYNA Yaşam Danışmanlığı

Mobil uyumlu statik tanıtım sitesi. HTML, CSS ve JavaScript kullanır. Derleme veya paket kurulumu gerekmez.

## Başlangıç

1. Bu klasörün **içindeki** `index.html`, `styles.css`, `script.js` ve `assets` klasörünü GitHub deponun kök dizinine yükleyin.
2. `script.js` dosyasındaki `CONTACT_EMAIL` alanına işletmenin e-posta adresini yazın. Bu alan boşken form gönderim yapmaz.
3. GitHub Pages ya da ticari kullanıma uygun bir hosting üzerinde yayımlayın. Depo Private ise hosting desteğini ve ücretleri kontrol edin.
4. Canlı yayından önce alan adı, KVKK aydınlatma metni, ticari iletişim, mesafeli hizmet sözleşmesi / iptal koşulları, vergi ve ödeme altyapısı gereksinimlerini değerlendirin.
5. Eğitim ortaklığı ve sertifika doğrulamalarını tamamlayın. Gerçek iletişim bilgileri olmadan müşteri başvurusu alınamaz.

## Notlar

- Bu sürümde ödeme veya otomatik randevu altyapısı **yoktur**.
- Form sunucuya veri göndermez; yapılandırıldığında ziyaretçinin e-posta uygulamasını açar.
- Belgelerin hassas kimlik bilgileri siteye konulmamıştır.
- `assets/ayna-kapak.png` kullanıcı tarafından onaylanan marka görselidir.
